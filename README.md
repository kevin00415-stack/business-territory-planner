# 業務責任區規劃系統（測試版）

營業所主管用的 Windows 電腦版工具：把各車客戶標在地圖上，拖曳界線重劃業務責任區，一鍵產出「營業所區域規劃資料變更表」。

- 介紹與使用教學：https://sales-satellite-app.pages.dev/official/region.html
- 下載：請到右側 **Releases** 下載 `BusinessTerritoryPlanner-Portable-*.zip`

## 使用方式

1. 下載 ZIP，按右鍵「全部解壓縮」到電腦硬碟（例如「文件」）。
2. 打開資料夾，雙擊「業務責任區規劃系統.exe」。
3. 需求：Windows 10／11（64 位元）、Microsoft Edge WebView2（Windows 11 已內建）。
4. 測試版沒有付費程式碼簽章，第一次執行若出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。

銷售明細與客戶清冊只在使用者的電腦處理，不會上傳。
